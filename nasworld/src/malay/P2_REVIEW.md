# Dunia Melayu, Primary 2 layer: review sheet

**STATUS: AWAITING HUMAN REVIEW BY A MALAY SPEAKER.** Nothing below has been checked by a person yet.

This sheet lists every Malay word and sentence added for the ten Primary 2 skills, each with the English meaning the child is shown after answering. It is written out from `src/malay/malay-data.js` and `src/malay/malay-lessons.js` by `node test/make-p2-review.js`, so please do not edit it by hand: correct the data file, then run that command again.

**For the reviewer.** Thank you for checking these. For each row, tick **OK** if the Malay is correct standard Bahasa Melayu as taught in Singapore primary schools, the English meaning is right, and the answer shown is the only choice that could be marked correct. Otherwise write the correction under **Fix**. Things worth a second look:

- spelling, and any word that is Indonesian or Malaysian usage and not Singapore school usage
- a wrong choice that a teacher would in fact accept (please name it, and it will be removed)
- for Bina Ayat, any other order of the same words that is also a good sentence
- anything too hard, or not taught, in Primary 2

Aligned to: Sukatan Pelajaran Bahasa Melayu Sekolah Rendah 2015 (MOE Singapore). Nothing is copied from a published book or a past paper.
