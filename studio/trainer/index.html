Answer Trainer

Decode the question, choose the words, build the chain, then write it.

What is this for

Booklet B marks are lost in three places: not seeing what the question actually asks, reaching for an everyday word where a scientific one is required, and stating the start and the end of a process while leaving out the middle. This trainer takes one question and walks those three separately, before you write anything.

No questions match that combination. Try a different topic or command word.
